# QuizRow

Браузерная игра «пять в ряд» с викториной по Dota 2. Играйте с другом по сети или с ботом. Верный ответ позволяет поставить знак; цель — собрать пять подряд.

Создайте комнату, отправьте другу ссылку или код и начните игру, когда он подключится.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm start
```

Откройте [игру](http://127.0.0.1:4173/).

Сетевой режим требует работающего Node.js-сервера. Для доступа из локальной сети задайте `HOST=0.0.0.0` и открывайте сайт по адресу компьютера с сервером. `PORT` задаёт порт (по умолчанию `4173`). Для игры через интернет нужен сервер на общем публичном адресе.

Комнаты хранятся в памяти сервера. Перезапуск сервера, перезагрузка страницы или выход игрока завершают участие в партии. При кратком обрыве связи игра ждёт переподключения до 30 секунд.

Проверки: `npm test`.

Данные героев — [OpenDota](https://github.com/odota/dotaconstants), [лицензия MIT](data/OPENDOTA-LICENSE).
