# QuizRow

Браузерная игра «пять в ряд» с викториной по Dota 2. Можно играть вдвоём за одним экраном или с ботом. Верный ответ позволяет поставить знак; цель — собрать пять подряд.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm start
```

Откройте [игру](http://127.0.0.1:4173/).

Проверки: `npm test`.

Данные героев — [OpenDota](https://github.com/odota/dotaconstants), [лицензия MIT](data/OPENDOTA-LICENSE).
